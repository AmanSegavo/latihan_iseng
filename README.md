# Karena otak tidak akan terasah oleh kebijakan yang hanya menyuruh rakyat patuh, saya memilih mengasahnya sendiri.

Latihan mandiri terus-menerus:
membongkar masalah, memahami logika, mencari bug, dan membangun solusi tanpa bergantung pada slogan, pencitraan, atau program yang lebih sibuk membuat laporan daripada menghasilkan kemampuan nyata.

Kalau sistem pendidikan terlalu sering mengajarkan cara mengikuti instruksi,
maka proyek ini saya gunakan untuk belajar mempertanyakan instruksi,
memahami masalah,
dan mencari solusi sendiri.
